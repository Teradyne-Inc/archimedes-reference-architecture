Kroki Tutorial - Creating Diagrams with Text

Kroki is a service that generates diagrams from text code. It supports many diagram formats.

🎯 What is Kroki?

Kroki unifies multiple diagram tools into a single API. Instead of installing PlantUML, Mermaid, GraphViz separately, Kroki manages them all.

📚 Supported Formats

  • Mermaid - Flow diagrams, sequences, Gantt charts
  • PlantUML - UML and sequence diagrams
  • GraphViz - Graphs and relationships
  • Excalidraw - Hand-drawn style diagrams
  • BlockDiag - Simple block diagrams
  • And many more...

DocFX directly supports Mermaid with the Markdig extension:

    C -->|Error| E[Response 500]

🔧 Integration in Your Project

Option 1: Use Mermaid directly in DocFX

Your docfx.json already has Markdig configured, which natively supports Mermaid!

Option 2: Generate static images with Kroki

import requests
import base64

def create_kroki_diagram(code, diagram_type='mermaid', format='svg'):
    url = f"https://kroki.io/{diagram_type}/{format}"
    response = requests.post(url, data=code.encode('utf-8'))
    return response.content

# Example
mermaid_code = """
graph LR
    A[Test] --> B[DAS]
    B --> C[Database]
"""

svg = create_kroki_diagram(mermaid_code)
with open('diagram.svg', 'wb') as f:
    f.write(svg)

Option 3: Encoded URL for Markdown

import base64
import zlib

def encode_kroki_url(code, diagram_type='mermaid'):
    compressed = zlib.compress(code.encode('utf-8'), 9)
    encoded = base64.urlsafe_b64encode(compressed).decode('ascii')
    return f"https://kroki.io/{diagram_type}/svg/{encoded}"

# Usage
code = "graph TD; A-->B;"
url = encode_kroki_url(code)
print(f"![Diagram]({url})")
