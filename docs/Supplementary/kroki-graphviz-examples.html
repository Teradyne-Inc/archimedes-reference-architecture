State Machine

A state machine diagram for DAS connection states:

stateDiagram-v2
    [*] --> Disconnected
    Disconnected --> Connecting : Connection Attempt
    Connecting --> Initialized : INITIALIZATION OK
    Connecting --> Error : No Response / Invalid
    Initialized --> Active : First Message Received
    Active --> Active : Heartbeat / Messages
    Active --> Disconnected : SHUTDOWN
    Active --> Error : Timeout / Invalid Msg
    Error --> Connecting : Retry
    Error --> Disconnected : Max Retries
    Disconnected --> [*] : System Stop
    
    state Active {
        [*] --> Receiving
        Receiving --> Processing
        Processing --> Responding
        Responding --> [*]
    }

Class Hierarchy

        +String URL
        +int Port
        +List~String~ MessageList

        +HttpContext Context
        +Listen() void
        +HandleRequest() void

Hand-Drawn Style Diagram (Excalidraw)

For a more informal, sketch-like appearance, you can use Excalidraw diagrams. This style is great for brainstorming and informal documentation.

Note: To create Excalidraw diagrams:

  1. Visit excalidraw.com
  2. Create your diagram with the hand-drawn style
  3. Export as PNG or SVG
  4. Save it to your media folder and reference it with ![description](media/filename.png)

Alternatively, you can use Mermaid with a sketch-like style as shown below.

Example: Mermaid with Hand-Drawn Theme

While Mermaid doesn't have a native hand-drawn style, you can use sketchy connectors:

Tips for Creating Mermaid Diagrams

Available Diagram Types

  • graph / flowchart - Flow diagrams
  • sequenceDiagram - Sequence interactions
  • stateDiagram-v2 - State machines
  • classDiagram - Class structures
  • erDiagram - Entity relationships
  • gantt - Project timelines
  • pie - Pie charts

Styling

  • style NodeName fill:#color - Fill color
  • style NodeName stroke:#color - Border color
  • Use [Text] for rectangles
  • Use ([Text]) for rounded rectangles
  • Use [(Database)] for cylindrical database shapes
  • Use {{Text}} for hexagons

Connections

  • --> - Solid arrow
  • -.-> - Dashed arrow
  • ==> - Thick arrow
  • --- - Solid line (no arrow)
  • === - Thick line (no arrow)

Subgraphs

graph TB
    subgraph Name[Display Name]
        A[Node A]
        B[Node B]
    end

For True Graphviz Diagrams

If you need pure Graphviz functionality, use the Kroki URL method:

  1. Write your Graphviz code
  2. Encode it using: https://kroki.io/examples.html
  3. Embed the generated URL as an image
