Using Docker with the UltraEdge2000

This is the entry point for the Docker Reference Architectures related to Archimedes and the UltraEdge2000 PC.
Teradyne recommends using a Docker container to deploy applications to the UltraEdge2000 PC as it is globally known and supported in the industry, it is flexible, and it allows for easy deployment.
The UltraEdge2000 software provides an API to work with Docker directly from IGXL.

The articles on this site focus on the use of Docker for Archimedes and assumes prior knowledge of the tool. For details about Docker and containers in general, please refer to the following resources:

  • https://www.docker.com/
  • https://www.docker.com/resources/what-container/

There is one exception: to ensure proper foundation, the first article (Docker creation) provides a general summary about creating a Docker image.
