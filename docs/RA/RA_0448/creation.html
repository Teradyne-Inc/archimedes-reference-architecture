Generalized Steps to Creating Docker Image

  1. Ensure Docker is installed and running on your machine, otherwise, install Docker (Desktop).
  2. Create a working directory that contains project files and the Dockerfile.
  3. Create Dockerfile: a Dockerfile contains the instructions for building the image.
  4. Build Docker image: in these examples a set of bash scripts are used to perform these tasks.
  5. Verify image build was successful and run the container.

First (additional) step: Ensuring Correct Line Endings

IMPORTANT
Scripts and Python code should use LF (Line Feed) endings to work properly in Linux environments.

Although this step is not part of the Docker creation, it is essential to keep in mind as this simple issue may generate a lot of frustration and loss of time!

How to Convert CRLF to LF Using Notepad++

  1. Open the script in Notepad++.
  2. Go to Edit > EOL Conversion.
  3. Select Unix (LF).
  4. Save the file.

Verifying Line Endings

  • Look at the bottom-right corner of Notepad++.
    • Windows (CRLF) = Wrong
    • Unix (LF) = Correct

How to Create a Docker?

In this article, we’ll create a Docker container that runs a simple Python script. The script generates a file within the container.

A batch script is provided in the scripts folder to automate Docker image creation.

Script

#!/bin/bash

APPNAME="simpleapp"

echo "Docker image creation"
docker build -t $APPNAME .

echo "Docker image saving to a .tar.gz"
docker image save $APPNAME:latest | gzip > $APPNAME.tar.gz

echo "Cleanup"
docker image rm $APPNAME:latest

echo "Docker image list for control"
docker image list

Explanations

  • Builds a Docker image named simpleapp using the Dockerfile.
  • Saves the image as a .tar.gz for distribution.
  • Removes the local image to save space.
  • Lists remaining Docker images.

Verifying a Docker image

This script executes the previously created Docker image:

Script

#!/bin/bash

echo "Loading image..."
docker image load < simpleapp.tar.gz

echo "Displaying image list..."
docker images

echo "Running Docker container for simpleapp..."
docker run -it simpleapp:latest

echo "Checking executed containers..."
docker ps -a

echo "Extracting the generated file from the terminated container..."
docker cp `docker ps -aq`:/app/SheWalksInBeauty.txt .

echo "Performing cleanup..."
docker rm `docker ps -aq`
docker image rm simpleapp:latest

Explanations

  • Loads the Docker image from the .tar.gz file.
  • Lists available images.
  • Runs the container using simpleapp:latest.
  • Checks which containers were executed.
  • Extracts the generated file from the container.
  • Cleans up the container and image.
