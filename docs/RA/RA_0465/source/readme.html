RA_0465 – Adaptive Test DAS Example (Source)

This source/ directory contains scripts and examples for the RA_0465 architecture, demonstrating an Adaptive Test flow using a Data Analytics Solution (DAS) in the AMP ecosystem.

Contents

  • AMP_adaptive_command.py
    Python script for issuing or preparing adaptive commands (modifying test conditions, sequences, or dynamic parameters).

  • AMP_adaptive_rmqclient.py
    RabbitMQ (or compatible messaging) client for publishing/consuming state or adaptation messages between AMP and the execution engine. Serves as a dynamic interface for the adaptive loop.

  • sample_code.py
    Simplified example showing how to integrate adaptive logic or call the main components. Use this as a starting point for your own extensions.

  • pymd_cli.bat
    Batch script to facilitate running Python commands (for quick use on Windows without typing the full command). Can be used as a launcher or utility.

  • RA_0465.zip
    Archive containing all files in this folder for download or distribution.

Purpose

This module provides a foundation for:

  • Experimenting with adaptive test strategies
  • Demonstrating asynchronous communication (AMP/DAS messages)
  • Extending to real-world scenarios (dynamic binning, conditional stop, parameter adjustment)

Usage

  1. Check your Python environment (recommended version as per the main documentation).
  2. Install any required dependencies (not listed here – see main documentation if provided).
  3. Start the messaging client (AMP_adaptive_rmqclient.py) if using a queue/broker.
  4. Run AMP_adaptive_command.py to simulate or control adjustments.
  5. Use sample_code.py as a template for your own adaptive rules.

Recommendations

  • Log adaptive decisions (separate log file) for post-lot analysis.
  • Use correlation IDs to link messages, decisions, and results.
  • Handle network exceptions (timeouts/broker unavailability) for robustness.
