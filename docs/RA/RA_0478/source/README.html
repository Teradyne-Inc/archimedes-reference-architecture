RA_0478 – DAS Listener Library (Source)

This source/ directory contains the implementation of the DAS Listener library for the RA_0478 architecture. It provides the necessary components to build and integrate a Data Analytics Solution (DAS) listener into your projects.

Purpose

This module demonstrates:

  • How to implement a DAS Listener library for handling AMP messages.
  • Integration with C++ projects using the provided API.
  • Real-world examples of DAS Listener usage.

Usage

  1. Navigate to the DASListener/ directory.
  2. Build the library and examples using CMake: 
    mkdir build && cd build
cmake ..
cmake --build .
  3. Run the example application to test the DAS Listener: 
    ./DASListenerExample
  4. Integrate the library into your own projects by including the headers and linking against the compiled library.

Recommendations

  • Ensure your environment meets the requirements specified in the README.md file inside the DASListener/ directory.
  • Use the examples as a starting point for integrating the DAS Listener library into your projects.
  • Log all AMP messages for debugging and analysis.
