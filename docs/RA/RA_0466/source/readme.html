RA_0466 DAS Listener - Source Files

This folder contains the source code and resources for the RA_0466 Data Analytics Solution (DAS) Listener reference implementation. The solution demonstrates how to build and run a DAS listener using Python and Docker, with supporting scripts and configuration files.

    Main Python script implementing the DAS listener logic.

  • Dockerfile
    Docker build file for containerizing the DAS listener.

  • makedocker.sh
    Shell script to build the Docker image for the DAS listener.

    Batch script to enable or configure the DAS listener on Windows systems.

    Example configuration file for simulating DAS operation.

    Example IG-XL file for integration or simulation purposes.
