## Installation using scripts

Installation using Microsoft Powershell scripts is much simpler.

Scripts must be run as administrator.

There are two flavors:

  • From the ISO file. This can be used for initial installations or to restart from scratch.
  • From an existing VHDX. The setup is much faster, because the entire system is already installed and available.

In both cases, the scripts automate all the steps detailed in the Manual installation.

  • The scripts execute the following sequence:
  • Preliminary verifications (does the Virtual Machine already exist, …)
  • If Hyper-V is not activated, automatically activate the Hyper-V feature.
  • Create the virtual machine.
  • Setup the network.
  • Setup the security option.
  • Assign the ISO file to the DVD drive or attach the VHDX disk to the Virtual Machine.
  • Launch the Virtual Machine.

If the installation is done through the ISO file, refer to the Linux installation section to do the installation. You can download the scripts from here Scripts
